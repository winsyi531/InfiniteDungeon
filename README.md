# 無限地城 Infinite Dungeon

像素風自動戰鬥 Roguelite。布丁小雞一層一層往下探索，戰鬥自動進行，你只要在每場勝利後挑選成長卡牌。

直接用瀏覽器打開 `index.html` 就能玩，不需要安裝任何東西。

## 玩法

- 每層 4 個節點：**戰鬥 → 戰鬥 → 營火 → 首領**
- 戰鬥勝利：回復 15% 生命，從 3 張卡中選 1 張（菁英怪必出稀有以上）
- 營火：休息回復 50% 生命，或從 2 張稀有／史詩卡中挑一張
- 首領：血量過半進入**狂暴**，每 4 回合施放**無法閃避的重擊**；擊敗後全回復並挑一件首領寶物
- 每 3 層換一個地城主題，怪物會越來越強，看你能撐到第幾層

快捷鍵：`1` `2` `3` 選卡、`S` 切換戰鬥速度（x1 / x2 / x4）、`M` 音效開關

## 檔案

| 檔案 | 內容 |
| --- | --- |
| `index.html` / `style.css` | 介面 |
| `main.js` | 遊戲流程、動畫、音效、背景 |
| `src/engine.js` | 戰鬥邏輯（純邏輯、不碰 DOM，可在 Node 中跑平衡模擬） |
| `src/cards.js` | 卡牌池與抽卡權重 |
| `src/sprites.js` | 所有像素圖，以字元陣列表示，可以直接手改 |

## 怪物

| 怪物 | 出現樓層 | 特性 |
| --- | --- | --- |
| 史萊姆 | 1+ | 每回合再生 5% 生命 |
| 吸血蝙蝠 | 1+ | 高閃避，攻擊時吸血 |
| 毒菇怪 | 1+ | 攻擊有機率讓你中毒 3 回合 |
| 骷髏劍士 | 2+ | 高防禦 |
| 幽靈 | 3+ | 高閃避，攻擊無視一半防禦 |
| 毛帽大王 | 每層首領 | 狂暴、蓄力重擊 |
